14주차 · 평가·최적화 및 보안RAGAS 실험실

내 RAG 앱을 숫자로 재 보기

Dify 공유 링크와 질문 몇 개만 있으면 됩니다. 앱에 질문을 보내 답변과 검색 근거를 모으고, 판사 LLM이 RAGAS 4대 지표로 채점합니다.

1

RAG 앱 연결

Dify에서 앱 → 게시(Publish) → 웹앱 열기(Run App)의 주소를 붙여넣으세요. 검색 근거를 받으려면 앱의 Features에서 Citations and Attributions가 켜져 있어야 합니다.

2

평가셋 만들기

실제 사용자가 물을 법한 질문을 쓰세요. 정답을 쓰면 검색 지표(Context Precision·Recall)까지 잽니다. 문서에 답이 없는 질문도 1~2개 넣어 보세요. 그때 정답은 비워 둡니다. 슬라이드 20

3

측정하기

질문 하나에 몇 초~수십 초가 걸립니다. 시작하면 페이지를 닫아도 계속 진행되고, 실행 기록에서 결과를 볼 수 있습니다. 한 번에 하나만 고치고 다시 재세요. 슬라이드 48

실행 기록

공격 프롬프트로 가드레일 점검 슬라이드 22–33

평가 실행 탭에 입력한 앱으로 공격 프롬프트 5개를 보냅니다. 답변을 읽고 각 공격을 막았는지 직접 판정하세요. 레일을 추가한 뒤 다시 점검해 전후를 비교합니다.

    결과는 판사 LLM의 판정이며 실행마다 조금씩 흔들립니다. 같은 평가셋으로 전후를 비교하세요. 슬라이드 19
